# M. Fadhli Maulana — Portfolio Website

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, typography, and responsive styles
- `script.js` — mobile navigation and current year
- `profile-photo.jpg` — add your own portrait using this exact filename

## Run locally
1. Extract the ZIP file.
2. Add a professional portrait named `profile-photo.jpg` to this folder.
3. Open `index.html` in a browser.

## Before publishing
Update the email address, LinkedIn URL, and Upwork URL in `index.html`.
Review the education and experience descriptions for accuracy.
Replace the sample project descriptions with real work samples. Do not publish confidential client or employer information.

## Publish free with GitHub Pages or Vercel
Upload the project files to a GitHub repository, then import that repository into Vercel and deploy. The site is static and does not require a backend.
